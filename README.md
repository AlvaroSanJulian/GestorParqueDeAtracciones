# GestorParqueDeAtracciones
Tecnologías utilizadas: Java, Programación Orientada a Objetos (POO), herencia, polimorfismo, ArrayList, excepciones y Collections.      Funcionalidades: gestión de atracciones infantiles y extremas, sistema de visitantes, ordenación de datos mediante Collections, menús interactivos y manejo de excepciones personalizadas.
