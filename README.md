# 🎢 Gestor Parque de Atracciones

Proyecto realizado en 1º de DAW en el que se desarrollan las siguientes funcionalidades:

  * Gestión de atracciones infantiles y extremas.
  * Sistema de visitantes.
  * Ordenación mediante Collections.
  * Menús interactivos.
  * Manejo de excepciones personalizadas.

## 🛠️ Tecnologías utilizadas

- Programación Orientada a Objetos (POO)
- Arrays y matrices
- Herencia
- Polimorfismo
- Clases abstractas
- Interfaces
- Enum
- ArrayList
- Excepciones personalizadas
- Collections


### Parte 1 - Fundamentos

---

En esta primera parte trabajé los conceptos básicos de programación
utilizando arrays bidimensionales y diferentes estructuras de control.

Se realizan ejercicios relacionados con la gestión de visitantes
de diferentes atracciones.

**Conceptos trabajados:**

- Arrays bidimensionales
- Bucles for y while
- Condicionales
- switch
- Recorrido de matrices
- Búsqueda de valores mínimos
- Gestión de datos


### Parte 2 - Programación Orientada a Objetos

---

En la segunda parte se transforma el proyecto para aplicar Programación Orientada a Objetos.

Se crea una clase abstracta `Atraccion` de la que heredan `AtraccionInfantil` y `AtraccionTerror`.

También se incorpora la interfaz `Accesible` y el enum `EstadoAtraccion`.

**Conceptos trabajados:**

- Clases y objetos
- Clases abstractas
- Herencia
- Polimorfismo
- Interfaces
- Encapsulación
- Sobreescritura de métodos
- Enum

### Parte 3 - Colecciones y excepciones

---

En la tercera parte se amplía el proyecto utilizando estructuras de datos dinámicas.

Los arrays utilizados anteriormente se sustituyen por `ArrayList`, permitiendo gestionar las atracciones de una forma más flexible.

También se añaden excepciones personalizadas para controlar situaciones en las que una atracción no está disponible.

Por último, se utiliza `Collections.sort()` para ordenar las atracciones según su precio.

**Conceptos trabajados:**

- `ArrayList`
- `Collections`
- `Comparator`
- Excepciones personalizadas
- `try / catch`
- Gestión de errores
- Ordenación de objetos
